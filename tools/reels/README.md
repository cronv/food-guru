# Генератор рилсов

Вертикальные видео 1080×1920 по 20 секунд. Кадры рисуются Pillow, склейка — ffmpeg.
Фотостоки не используются: вся графика рисуется кодом, права на результат ваши.

## Запуск

```bash
pip install -r requirements.txt   # нужен ещё ffmpeg в системе
python3 make_reel.py              # фондан       → fondan-reels.mp4
python3 make_pasta_reel.py        # паста        → pasta-reels.mp4
```

Рендер занимает около 9 минут на 480 кадров — это нормально, считается на процессоре.

## Как добавить рецепт

`make_reel.py` — это движок: фон, столешница, свет, тени, блики, карточки подсказок,
прогресс. `make_pasta_reel.py` — пример того, как им пользоваться: он импортирует
движок и описывает только свои сцены.

Чтобы сделать ролик для нового рецепта, скопируйте `make_pasta_reel.py` и замените:

1. `ING` — список ингредиентов с граммовками, они сами добегают до значения на экране;
2. функции сцен — что рисуется на каждом шаге;
3. `SCENES` — длительности. Сумма должна давать 20 секунд, скрипт это проверяет.

Подсказки с цифрами (`E.hint_card`) — главное, ради чего ролик существует:
температура, время, «не больше двух минут». Их ставьте в каждую сцену.

## Рендер в Docker

Ни ffmpeg, ни Pillow на машине ставить не нужно — всё считается в контейнере
(`Dockerfile` рядом: python:3.12-slim, ffmpeg, шрифт Inter, Pillow).
Из корня репозитория, PowerShell:

```powershell
docker build -t reels-render tools/reels
docker run --rm -v "${PWD}:/work" -e REEL_OUT=/work/tools/reels/out reels-render python make_shakshuka_reel.py
```

Готовый ролик появится в `tools/reels/out/<slug>.mp4` (1080×1920, 20 с, H.264, faststart).
Четыре контейнера можно гонять параллельно, каждый занимает около 9 минут.

Новые ролики (общий код — `reel_kit.py`: раскладка сцен, подсказки, новые предметы):

| Скрипт | Рецепт | Файл | Граммовки |
|---|---|---|---|
| `make_tykvennyy_reel.py` | Тыквенный крем-суп с нутом | `tykvennyy-krem-sup.mp4` | на 4 порции |
| `make_shakshuka_reel.py` | Шакшука с фетой | `shakshuka-s-fetoy.mp4` | на 2 порции |
| `make_syrniki_reel.py` | Сырники на рисовой муке | `syrniki-risovaya-muka.mp4` | на 3 порции |
| `make_cacio_reel.py` | Паста качо-э-пепе | `pasta-cacio-e-pepe.mp4` | на 2 порции |

Количества пересчитаны с одной порции из `site/index.html` на число порций рецепта,
это написано в заголовке сцены ингредиентов.

Быстрая проверка без полного рендера — по одному кадру на сцену (экономит 9 минут):

```powershell
docker run --rm -v "${PWD}:/work" -v "${PWD}/prev:/prev" -e REEL_PREVIEW=/prev reels-render python make_shakshuka_reel.py
```

Переменные окружения: `REEL_OUT` (куда класть mp4), `REEL_PREVIEW`, `REEL_FONTS`.
Кадры новых скриптов не пишутся на диск, а идут по трубе прямо в ffmpeg.

## Шрифты

Берётся Inter из системы (`/usr/share/fonts/opentype/inter`). На другой машине
поправьте `FDIR` в `make_reel.py` или положите шрифты туда же.
